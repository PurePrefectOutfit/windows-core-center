## ⚙️ Paano ito Gumaganat (How It Works)

Ang proseso ng KMS Pico ay gumagamit ng "Key Management Service" emulation. Sa halip na kumonekta sa isang malayong server, bumubuo ang tool ng isang lokal na server sa iyong kompyuter upang magbigay ng mga valid na aktibasyon para sa Windows at Microsoft Office.

---

## 🚀 Gabay sa Aktibasyon (Activation Walkthrough)

**Hakbang 1 — I-disable ang Antivirus**
Bago simulan, pansamantalang i-off ang Windows Defender at anumang third-party antivirus dahil madalas nilang harangan ang mga file na may kinalaman sa KMS.

**Hakbang 2 — I-extract ang Archive**
Gamitin ang WinRAR o 7-Zip upang buksan ang downloaded folder. Siguraduhin na kumpleto ang lahat ng files.

**Hakbang 3 — Patakbuhin bilang Administrator**
I-right click ang `KMSPico_Setup.exe` at piliin ang **"Run as Administrator"**. Ito ay mahalaga upang magkaroon ng permiso ang tool sa system files.

**Hakbang 4 — Piliin ang Produkto**
Pumili kung nais mong aktibuhin ang Windows o ang Microsoft Office (o pareho).

**Hakbang 5 — Pag-restart ng PC**
Pagkatapos lumabas ng "Success" message, i-restart ang iyong kompyutera upang gawing permanente ang aktibasyon.
